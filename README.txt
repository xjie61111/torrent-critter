ТОРРЕНТ-ЗВЕРЁК ДЛЯ WINDOWS

Запуск
Откройте torrent-client.exe. Добавляйте .torrent-файлы или magnet-ссылки кнопками или перетаскиванием .torrent в окно. В настройках можно зарегистрировать клиент для .torrent; Windows может попросить подтвердить приложение в стандартных приложениях. Окно адаптируется к размеру. На карточках показаны найденные/подключённые пиры и скорость, а прогресс отображается отдельной широкой полосой с мультяшными котиками: при загрузке бегают, прыгают и спотыкаются, а в ожидании и после завершения сидят и умываются. В настройках доступны три бегущих котика или режим с дерущимся клубком, пылью и новыми котиками, которые вбегают внутрь; клубок растёт с числом пиров. Правый клик в любом месте карточки открывает меню управления загрузкой. Левый клик по строке показывает или скрывает действия.

При добавлении загрузки выбирается папка назначения, внутри которой клиент создаёт отдельную подпапку по имени .torrent-файла без расширения. Флажок в окне добавления запоминает папку для следующих загрузок; это поведение также меняется в настройках. Повторное добавление использует уже существующие файлы в папке торрента.

Загрузки сохраняются между запусками: после повторного открытия клиент восстановит список и продолжит работу.

Настройки
• Выберите папку загрузки.
• Удаление исходного .torrent после добавления включено по умолчанию; отключается флажком.
• «Запускать вместе с Windows» добавляет приложение в автозапуск текущей учётной записи.
• Публичные трекеры используются как дополнительный способ найти пиры, включая HTTPS-трекеры для сетей, где UDP закрыт. Эта настройка отключается; private .torrent не получают публичные трекеры. В строке загрузки показывается размер таблицы DHT.
• Автоматическое открытие входящего порта через UPnP включено по умолчанию и отключается в настройках. Оно может помочь принимать больше входящих соединений, если роутер поддерживает UPnP; изменение применяется после перезапуска.
• Для диагностики включите «Показывать окно отладки сети» в настройках: там видны DHT, попытки/ошибки TCP и uTP, счётчики пиров, хэш и список трекеров каждой загрузки. Кнопка «Скопировать отчёт» кладёт сводку в буфер обмена; параметры трекеров скрываются.
• Диагностические сведения собираются только пока окно отладки открыто, чтобы снизить лишнюю работу интерфейса во время загрузки.
• В меню загрузки выберите «Пересчитать хеши частей», чтобы повторно проверить данные на диске. Проверка заново считывает и сверяет сохранённые части с контрольными значениями торрента.

Сборка из исходников
Запустите build.bat. При первой сборке Cargo скачает зависимости; готовый torrent-client.exe появится рядом с исходниками.

Приложение написано на Rust с движком librqbit и оболочкой egui.
